# The first automation I built with Claude Code

There was a report I was supposed to send myself every week.

Not to anyone else. To myself. A short summary of what had moved, what hadn't, what needed attention on Monday. A five-minute thing. Simple in theory.

In practice: I never did it. Every Sunday evening I told myself I'd do it Monday morning, and Monday morning I was already into things. The week started blurry. It always started blurry.

I had been meaning to sort this out for three months.


I set it up in one session with Claude Code. It took maybe forty minutes, including figuring out what I actually wanted.

Now, every Sunday at six, a summary arrives on Telegram. Calls I had that week. Things I marked as done. What I've flagged as priority for Monday. I read it before the week starts.

The week no longer starts blurry.


I'm not telling this story because the automation is impressive. It isn't. A developer could build it in an afternoon.

I'm telling it because this was the first thing I built that changed a habit — and I built it as someone who doesn't write code.

That's what people miss. You don't need to be technical to automate your life. You need to be clear about what you want.

Here is the conversation that started it, roughly:

"Every Sunday at 6pm I want to receive a Telegram message with a summary of my week. It should include: meetings I had, tasks I completed, and what I've marked as priority for next week. Pull from my calendar for meetings. I'll update a simple note for the rest."

Claude Code asked a few questions — what format, how far back, what counts as completed. I answered them. It built the thing.

That exchange took twenty minutes. The automation has run every week since. I have not thought about it.


The first automation is never the most impressive one.

It's the one that shows you what's possible. It's the one that makes the next one feel obvious. It's the one that — if you pick the right task — quietly removes something that was quietly costing you.

Pick the thing you've been putting off for three months. Not the ambitious one. The annoying one. The recurring task you keep meaning to sort out.

Build that one first.
